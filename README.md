## サービス概要

妖怪図鑑は、240体以上の妖怪を収録した妖怪図鑑iOSアプリ です。
図鑑として妖怪を眺めるだけでなく、コメントで語り合えたり、全国の妖怪イベントや最新ニュースを閲覧できます。
地図から妖怪ゆかりの町を知ることができます。

## 使用技術一覧

フロントはSwiftUIで、地図まわりはMapKitを使っています。
図鑑データはCloudflareのR2とWorkersから配信していて、アプリを更新しなくても全ユーザーに最新の妖怪が反映されます。
通信も、変更がなければETagの再検証だけで済むよう軽くしてあります。コメントの土台はFirebase(認証とFirestore)、イベントとニュースは外部フィードを取り込んで表示しています。
